Create a public repository named `maryammehrabani.github.io` in the `maryammehrabani` account. Upload the extracted contents of this archive to its root, including `assets`. Keep `index.html` at the top level. In Settings → Pages, choose Deploy from a branch, branch `main`, folder `/(root)`, then Save. No build or package installation is required.
