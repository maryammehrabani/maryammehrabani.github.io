Study design, statistical methods & sources

Eight samples from four human donors; one untreated and one dexamethasone-treated sample per donor. The original treatment was 1 µM dexamethasone for 18 hours.

Raw gene counts are from Bioconductor airway 1.32.0. Genes were retained with ≥ 10 counts in ≥ 4 samples. PyDESeq2 0.5.4 was executed using the paired negative-binomial model ~ donor + condition; the contrast is dexamethasone versus untreated. Wald tests use a zero log₂ fold-change null with Benjamini–Hochberg adjustment (α = 0.05). Fold changes are unshrunken. The downloadable package includes exact inputs, checksums, environment versions and results.

Original data: GSE52778 · airway · Himes et al., 2014.

The four-donor design has only three residual degrees of freedom; dispersion-prior estimation is less stable at this sample size. PCA uses design-informed VST values without donor removal. This is an exploratory public-data reanalysis. The package also includes an R/DESeq2 counterpart; that R script has not been executed here, and the displayed results were produced by PyDESeq2.
